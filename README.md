# MG4
## Devlog
The float animation works to animate the fish food object up and down by using start() to begin the animation with the timer and switch speed. In the code it then uses update () to allow the fish food to continously go up and down. The food goes up or down a certain direction before the timer moves it the other direction. On the fishfood object when you include the float animation it shows the move speed and switch speed which you can adjust to decide how fast it moves and how long it goes one direction before switching. The time spent it moves a direction is _timer. For _up if it is true the food goes up where if its false it moves down. After this _timer resets making it change direction.
